# Network Configuration Lab

A hands-on networking project focused on configuring network infrastructure, implementing VLANs and DHCP, assigning IP addresses, and verifying connectivity between devices.

## 🌐 Project Overview

The goal of this project was to configure and test a functional network environment using routing, switching, VLANs, DHCP, and IP addressing.

The project included configuring network devices, establishing VLANs on a switch, configuring DHCP addressing, and troubleshooting connectivity between devices.

## ⚙️ Network Configuration

### Router & DHCP Configuration

The network was configured to provide addressing to connected devices using DHCP.

The configuration process included:

- Configuring network addressing
- Configuring DHCP scopes
- Connecting client devices to the network
- Allowing DHCP to automatically assign IP configuration to client systems

### VLAN Configuration

VLANs were configured on the network switch to logically organize network traffic.

This portion of the project provided hands-on experience with:

- Switch configuration
- VLAN creation and configuration
- Network segmentation concepts
- Connecting devices through configured network infrastructure

## 🔍 Connectivity Testing

After configuration, connectivity between network devices was tested to verify that the network was functioning correctly.

One verification method used the `ping` command:

```text
ping 172.10.8.2
```

Successful ICMP replies were used to confirm communication between network devices.

DHCP assignment was also verified by confirming that the client computer automatically received an IP address from the configured network.

## 🧪 Verification Methods

Two primary methods were used to confirm successful network connectivity:

1. **Ping Testing**
   - Sent ICMP echo requests between network devices
   - Verified successful replies
   - Used the results to troubleshoot connectivity

2. **DHCP Verification**
   - Confirmed that the client system automatically received network configuration
   - Verified the assigned IPv4 address and network settings
